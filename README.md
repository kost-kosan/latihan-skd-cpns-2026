# Siap Abdi — GitHub Pages (demo/uji)

Aplikasi web (PWA) Siap Abdi — Latihan Soal CPNS, TNI, Polri & BUMN. Jalur CPNS tersedia: bank 709 soal (TWK 255, TIU 256, TKP 198, termasuk pilot Figural 15 soal), pembahasan, trik jawab cepat, Simulasi Mini 24 soal/22 menit dan Simulasi Penuh 110 soal/100 menit, freemium + Premium Rp20.000 (harga peluncuran s.d. 31 Desember 2026, lalu Rp85.000) via kode aktivasi. Jalur TNI, Polri, dan BUMN segera hadir.

**Status: DEMO/UJI — BELUM LAYAK JUAL.** Penjualan dilarang sampai vonis Go/No-Go (7/7 syarat). Soal Figural (gambar): pilot 15 soal tersedia di latihan; Simulasi Penuh (CAT) masih tanpa Figural. Aplikasi ini bukan aplikasi resmi BKN dan tidak menjamin kelulusan; soal dibuat sendiri, bukan soal asli/bocoran BKN.

Pasang di HP (Android, Chrome): buka tautan situs ini → menu titik tiga → "Pasang aplikasi" / "Tambahkan ke layar utama". iPhone: buka di Safari → Bagikan → "Tambah ke Layar Utama".

Bagikan: kirim tautan situs ini ke WhatsApp/Instagram (tautan di bio atau stiker tautan di Story).
